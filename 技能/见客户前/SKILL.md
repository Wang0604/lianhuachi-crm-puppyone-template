# 技能：见客户前

借鉴 Anthropic 销售插件的 call-prep：一页纸，见面前一分钟扫一眼就够。重点是「这次要拿下什么」，不是复述历史。

## 读什么

1. `数据/商机.csv` 里这一单那一行，以及 `统计/管道体检.csv` 里它的分类和风险。
2. 商机页：现状、事实、已对客户承诺的、待确认、AI 建议。
3. 客户页：背景、联系人情况、**雷区**。
4. `数据/联系人.csv` 里这家客户的人；这次要见谁，使用者 没说就问。
5. `数据/跟进记录.csv` 里这一单最近 5 条，以及它们指向的材料。

## 写什么（照这个格式，回复里直接给）

```text
## 见 <客户> · <日期> <场合>

一句话：<这一单现在到哪、卡在哪>

### 见谁
- <姓名>（<职位>，<角色>）：上次 <日期> 说「<原话>」【材料路径】；他在意 <……>（推断的写「推断」）

### 欠账
- 我方欠：<事>，原定 <日期>（逾期的标出来）
- 对方欠：<事>，原定 <日期>

### 这次要拿下的（最多 3 件）
1. <具体到对方能当场回答的问题或决定，比如「签约主体是哪家公司」>

### 可能的异议和怎么回
- 对方可能说：「<……>」（依据：<材料>）→ 回：<只用之前已经说过、或商机页里写过的回应>

### 别碰
- <客户页雷区；不能当场承诺的价格、范围、日期>
```

## 规矩

- 先确认见谁、什么场合。使用者 没说，而且排期里那天安排的是别的事，就先问，再按最合理的假设写，并写明假设。
- 联系人表里没有实名的人，「见谁」就照客户页的说法写（「群里的老板」），并把「问清在场每个人的名字、职位、谁拍板」放进「这次要拿下的」第一件。
- 赢单后还在交付的单不在管道体检里，「一句话」和「欠账」改看商机页的交付里程碑。
- 「这次要拿下的」从三处来：商机的下一步、商机页的待确认、管道体检的风险。比如体检说「只和一个人真实沟通过」，就写「请 <对接人> 引荐拍板人」。
- 每条事实都带来源。没有依据的判断写「推断」。
- 异议只写材料里出现过的。客户说过的写「依据：<材料>」；我方内部材料里预判的写「内部预判：<材料>」；都没有的，写「没有先例，现场先听」，不要替对方编台词。
- 不写新的报价、承诺、日期。需要的话，写进「这次要拿下的」，让 使用者 现场决定。
- 使用者 说「存一下」，就写进 `准备/YYYY-MM-DD <客户简称> <主题>.md`。准备稿不是事实来源，不能被商机页引用。
- 见完以后提醒他：「见完把纪要或录音扔给我」，接 `技能/会后纪要/SKILL.md`。
