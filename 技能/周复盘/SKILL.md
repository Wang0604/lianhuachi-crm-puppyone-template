# 技能：周复盘

1. 运行 `node 脚本/检查.mjs`。
2. 读 `看板.md`、`统计/每周.csv`、`统计/漏斗.csv`、`统计/目标进度.csv`，以及本周（周一到今天）的跟进记录。
3. 回复 使用者：
   - **KPI**：签约额和回款额各完成多少，比时间进度领先还是落后，中性预测还差多少。
   - **本周推进**：哪些商机有真实沟通，从什么状态走到什么状态。
   - **卡住的**：按 `统计/管道体检.csv` 的分类说，卡在哪、卡了几天、建议怎么破（做法见 `技能/管道体检/SKILL.md`）。
   - **下周最重要的三件事**。
   - **记录本身**：待确认有没有堆着，待补字段有没有补，阶段迁移有没有确认。
4. 使用者 要存档的，写到 `复盘/YYYY-Www.md`（例如 `复盘/2026-W42.md`）。
