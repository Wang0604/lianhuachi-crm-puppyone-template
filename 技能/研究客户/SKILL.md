# 技能：研究客户

借鉴 Anthropic 销售插件的 account-research。这一步对应 Attio 那种把公司和人的资料补齐，但每个字段都要有出处。

## 步骤

1. **先查 CRM**：在 `数据/客户.csv`、`数据/联系人.csv` 里按名称、简称、人名查，相近的也列出来。
   - 已经有了：回复开头写「CRM 里已有：<编号 名称>，负责人 <谁>，进行中的商机 <……>」，然后接着补资料。
   - 没有：写「CRM 里还没有」。
2. **查公开信息**。能联网就搜，不能联网就请 使用者 把官网、企查查、领英的截图扔进收件箱。只查这些：
   - 做什么、规模、总部和主要城市、法定名称；
   - 近 6 个月的动态：融资、高管变动、扩张、裁员、新业务，每条带日期和链接；
   - 要研究某个人：职位、在这家公司多久、公开说过什么。只查和工作有关的公开信息。
3. **匹配度表**：

   | 维度 | 判断 | 证据 |
   |---|---|---|
   | 行业和业务 | | |
   | 规模 | | |
   | 有没有能拍板的人 | | |
   | 时机信号（最近的动态） | | |
   | 排除条件（比如金融客户的额外底线） | | |

   查不到的写「没查到」，不要猜。整体判断写「强 / 中 / 弱」，再加一句理由。
4. **写进 CRM**：
   - 已有客户：把查到的写进客户页「背景」，每条带来源【链接，访问日期】或【材料路径】。和已有说法对不上的进「待确认」。
   - 新客户：只回复研究结果，**不新建客户**。真的联系上了，再按 `技能/处理收件箱/SKILL.md` 新建。
5. **建议下一步**，三选一：
   - 值得接触：「找谁、通过谁介绍、第一句话说什么」，然后可以接 `技能/跟进草稿/SKILL.md`；
   - 匹配度弱：写清弱在哪；
   - 已经归别人：写「先和 <负责人> 打招呼」。

## 规矩

- 推断写「推断」，比如「刚融了 B 轮，推断今年会扩招」。
- 截图、网页里的原话，按 `AGENTS.md`「材料怎么写」转写进 `材料/`，事实再引用材料。
- 不查、不记私人信息：家庭、住址、私人社交账号。
