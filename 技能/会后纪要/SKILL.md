# 技能：会后纪要

借鉴 Anthropic 销售插件的 call-summary。会议是信息最密的时候，也是承诺最容易漏的时候。

## 步骤

1. **原文照录进材料**：按 `技能/处理收件箱/SKILL.md` 第 1–3 步，写 `材料/<客户简称>/YYYY-MM-DD <渠道> <主题>.md`，性质写「录音转写」「纪要照录」或「口述」。原文一个字不改。
2. **按下面的格式整理**。每一条都要能在原文里找到，找不到的不写。

   | 小节 | 写什么 |
   |---|---|
   | 参与人 | 双方各有谁；对方的人能对上 `数据/联系人.csv` 就写编号，有名字但表里没有的新建联系人 |
   | 对方要什么 | 需求、目标、时间要求，用对方的原话 |
   | 对方的顾虑 | 异议、担心、比较过谁，用原话 |
   | 双方承诺 | 谁、做什么、哪天前。相对时间按开会那天换算，保留原话 |
   | 定下的事 | 会上明确拍板的 |
   | 没定的事 | 提了但没结论的，进商机页「待确认」 |
   | 下一步 | 25 字以内，进 `数据/商机.csv` |

3. **写进 CRM**，接 `技能/处理收件箱/SKILL.md` 第 4–9 步：跟进记录加一行（性质是沟通，「我方承诺」写我方答应的）；商机页更新现状、事实、已对客户承诺的、待确认；需要拍板的事（阶段、金额、新承诺）提建议，等 使用者 同意。
4. **起草一条会后确认消息**，按 `技能/跟进草稿/SKILL.md` 的口吻：谢谢时间；列出定下的事和双方承诺，各一行；只问一个没定的事。会后当天发最好。
5. **回复 使用者**：上面那张表（一屏以内）、草稿、要他拍板的事。

## 规矩

- 会上谁说的，就记谁说的。分不清是谁说的，写「说话人不清楚」，不要猜。
- 我方在会上说出口的，才算我方承诺；「我们回去研究一下」不算承诺，算「没定的事」。
- 转写里明显是识别错误的字词，在材料里照录，在整理时写「疑似识别错误：XX，可能是 YY」。
