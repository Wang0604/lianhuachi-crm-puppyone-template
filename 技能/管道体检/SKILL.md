# 技能：管道体检

借鉴 Anthropic 销售插件的 pipeline-review，以及一个 HubSpot 管道清理技能的四象限分类。数字由脚本算，你负责解释和给动作。

## 脚本怎么分

运行 `node 脚本/检查.mjs`，结果在 `统计/管道体检.csv` 和 `看板.md` 的「管道体检」一节。

| | 最近有真实沟通（`停滞天数` 以内） | 最近没有 |
|---|---|---|
| **在当前阶段没停太久** | 健康 | 该推一下 |
| **停太久了**（超过 `卡住天数`，没设就是停滞天数的两倍） | 卡住了 | 快死了 |

「在当前阶段停了多久」从 `数据/阶段变更.csv` 里这一单最后一次真正的换阶段算起；依据以「迁移」「更正」开头的行，以及原阶段、新阶段相同的确认行，都不算。依据里写了「进入日期：YYYY-MM-DD」的行，直接用那个日期。

「最近有没有真实沟通」只看这一单自己的跟进记录，不借用同一家客户其他单的。赢单后还在交付的单不进体检，交付进度看商机页的交付里程碑。

另外标两种风险：

- **单线程**：这一单只和一个人真实沟通过，或者一个都没有。那个人一走或者一沉默，单子就断了。
- **预计成交日已过**：日期过了，单子还没结束。

## 每一类给什么动作

| 分类 | 动作 |
|---|---|
| 该推一下 | 发一条不提要求的消息（给有用的信息、兑现一个小承诺），按 `技能/跟进草稿/SKILL.md` 写 |
| 卡住了 | 在商机页的「待确认」里找卡点，提一个对方能当场回答的问题 |
| 快死了 | 建议最后试一次（写出具体那条消息），或者建议转输单。转输单是改阶段，要 使用者 同意 |
| 单线程 | 请现在的对接人引荐拍板人或第二个人，写出怎么开口 |
| 预计成交日已过 | 问对方新的时间；对方明确说了，再更新预计成交日 |

## 回复（一屏以内）

1. 一句话：进行中几单，四类各几单。
2. 表格：只列不健康或有风险的单，按「快死了 → 卡住了 → 该推一下」排序。列：商机、分类、停了几天、风险、建议动作。
3. 这周最该做的三件事。

## 规矩

- 只读。不改阶段、不改预计成交日、不删任何东西。
- 「不知道进入当前阶段的日期」，或者你从材料看出停留天数明显不对（比如一行更正被当成了换阶段），提醒 使用者 补一句「XX 是哪天进的这个阶段」。他说了以后，按 `AGENTS.md`「更正一次记错的阶段」加一行，依据里写「进入日期：YYYY-MM-DD」。
- 单数少的时候也照样分类，但要说明「样本少，分类只是提醒」。
