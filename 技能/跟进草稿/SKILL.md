# 技能：跟进草稿

1. 读这一单的商机页、`数据/商机.csv` 那一行，以及 `数据/跟进记录.csv` 里最近几条和它们指向的材料。
2. 写一到两版微信草稿。口吻像 使用者 本人：短、口语，一条消息只说一件事。
3. 草稿里不能出现商机页里没有的承诺、价格、日期。需要新承诺的，先问。金融客户守住 `AGENTS.md` 里的额外底线。
4. 只给草稿，不发送。

使用者 发出去之后，让他发截图，或者说一句「发了」。说「发了」的，按草稿原文写一份材料（性质写「口述：已发送」），再在跟进记录末尾加一行，性质是沟通。
