# 技能：开场带路

使用者 多半不会去读说明，所以由你带路：先看清 CRM 现在的状态，再告诉他做什么、去哪看、下一句说什么。其他技能是这条链上的单个步骤，这份文件把它们串起来。

## 第 0 步：开场体检（每次对话开始，先默默做完）

1. `date +%F` 确认今天。运行 `node 脚本/检查.mjs`，读它的输出和 `看板.md`。
2. 记下五件事：表格错误几个、收件箱几份、今天要跟和过期的几单、管道体检里「快死了」「卡住了」几单、要拍板和待补的几条。
3. 先做什么，按这个顺序：**表格错误 > 收件箱 > 使用者 提的要求**。他一上来就提了具体要求，就先满足他，体检结果放在回复最后一句提一下。

## 他只说了「你好」「开始」

用这个开场，不超过 6 行：

- 收件箱有几份没处理（有就问要不要现在处理）；
- 今天要跟的前 3 单，过期的排最前，每单一行写为什么要跟；
- 管道体检：哪一单最危险，一句话；
- 有几件等他拍板、几条待补；
- 最后一行给「下一句可以说」。

## 日常：听到什么，走哪一步

| 使用者 说的，或者发生的事 | 读 |
|---|---|
| 发来截图、聊天、口述进展 | `技能/处理收件箱/SKILL.md` |
| 「明天见 XX」「帮我准备一下」 | `技能/见客户前/SKILL.md` |
| 发来会议录音转写、纪要，「刚开完会」 | `技能/会后纪要/SKILL.md` |
| 「帮我回」「怎么回他」，以及「发了」 | `技能/跟进草稿/SKILL.md` |
| 「今天跟谁」「KPI 怎么样」 | `技能/今天跟谁/SKILL.md` |
| 「哪些单有问题」「管道怎么样」「该放掉哪些」 | `技能/管道体检/SKILL.md` |
| 「研究一下 XX」「XX 是什么公司」 | `技能/研究客户/SKILL.md` |
| 「周复盘」；或者今天是周五到周日，这周还没做过周复盘（在回复最后问一句「要做周复盘吗？」） | `技能/周复盘/SKILL.md` |
| 他说了一个决定（「阶段改成谈判」「金额是 9.6 万」） | `AGENTS.md`「必须先问 使用者，同意后再做」：他已经同意了，照做 |

一天下来是这个圈：**见客户前准备 → 见完扔材料 → 你记账 → 看板排好 → 你写草稿 → 他发出去 → 他说「发了」 → 你记一笔**。拍板、补字段、周复盘插在圈的任何地方。

## 每一轮结束都要做（收口）

1. 运行 `node 脚本/检查.mjs`，错误修到 0。
2. 回复写三件事：改了哪几单、新增了哪些事实和承诺、哪些事等他拍板。没有的就不写。
3. 告诉他去哪看，路径写全，比如 `看板.md`、`商机/O-003 澄光 咨询报名自动化.md`。
4. 最后一行给「下一句可以说」，最多 3 个，按当前状态挑。例如：
   - 收件箱还有材料：「处理收件箱」；
   - 有草稿：「帮我改短一点」「发了」；
   - 明天有会：「帮我准备一下明天见 XX」；
   - 有拍板：「同意」「不同意，改成……」；
   - 都没有：「今天跟谁」「管道怎么样」。

## 什么时候必须停下来问

- 认不出是哪个客户，或者可能是两个。
- 阶段、金额、回款、新承诺、报价：提建议和依据，等他同意。
- 要写进事实的说法和已有的对不上：两种都进待确认。
- 改 `设置/`、改 `材料/` 里已有的文件、删除任何东西：一律由他本人做。
