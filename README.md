# 莲花池 CRM · PuppyOne 模板

把截图、聊天、会议纪要或口述交给 AI，让它维护客户与商机；用表格保存事实，用脚本生成看板。你负责拍板和对外沟通。

**这里的 8 家公司、12 位联系人、10 个商机以及全部沟通和回款都是模拟数据。** 可以直接体验完整销售流程，详见 [模拟数据说明](模拟数据说明.md)。

## 在 PuppyOne 里开始

1. 点击 GitHub 的 **Use this template → Create a new repository**，选择 **Private**，创建自己的副本。确认副本是私有后，再放入真实业务资料。
2. Clone 你的私有副本，用 PuppyOne 打开这个文件夹。
3. 在 PuppyOne 终端启动已安装并登录的 AI 工具，例如 `claude`、`codex`、`cursor-agent` 或 `opencode`。请它先读 [AGENTS.md](AGENTS.md)。
4. 电脑需要 Node.js 18 或更高版本。运行下面的命令，或者让 AI 帮你运行：

```sh
node 脚本/检查.mjs
```

5. 对 AI 说 **「你好」**，然后查看 [看板.md](看板.md)。

想先体验公开样例，可以直接克隆本仓库。体验期间只用模拟资料；录入真实客户之前仍需建立私有副本并检查远程地址。

```sh
git clone https://github.com/Wang0604/lianhuachi-crm-puppyone-template.git
cd lianhuachi-crm-puppyone-template
node 脚本/检查.mjs --today 2026-10-17
```

样例以 **2026-10-17** 为基准日。带 `--today` 可复现出厂看板；默认命令按电脑当天日期计算逾期与停滞。示例币种换算系数仅用于演示。

| 案例 | 演示重点 |

| 岚屿装备：售后知识库试点 | 长时间无沟通，预计成交日也已过 |
| 澄光教育：咨询报名自动化 | 报价阶段、多人对接、今天要跟 |
| 星苇文创：渠道客户台 | 合同法务阶段，尚未签约 |
| 松汀餐饮：加盟意向整理 | 预算未知，提醒补需求，不编金额 |
| 知栈软件：伙伴门户改版 | 美元签约、部分回款、赢单后交付 |
| 云禾农品：经销商线索录入 | 输单原因与过程留存 |

## 换成你的业务

在你自己的**私有副本**里，把 `设置/参数.csv` 的「我的名字」、目标、阶段和汇率改成你的规则。让 AI 帮你清空模拟的客户、联系人、商机、跟进、阶段变更和回款记录，保留六张表的表头，移除对应模拟客户页、商机页和材料，再运行检查脚本。不要把真实资料提交回这个公开仓库。

阶段、金额、回款和对客户的新承诺必须先得到你确认。「我的判断」由你自己填写，AI 只给建议。跟进、阶段变更和回款表只追加；材料写好后只新增，不覆盖。

样例不含账号凭证、原始聊天附件、历史归档、数据库或后台同步任务。公开模板不自动提交、不自动推送，也不会连接任何私有演示库。

## 开发与发布检查

```sh
node 脚本/检查.mjs --today 2026-10-17
node --test 脚本/检查.test.mjs
node 脚本/公开检查.mjs
```

公开检查会拒绝常见密钥、私人绝对路径、IP 地址、电话号码、非示例邮箱，以及归档、数据库和附件。它只作辅助；发布者仍需人工核对公司、人名、沟通、合同和金额是否为模拟资料，并确认没有带入私人 Git 历史。
